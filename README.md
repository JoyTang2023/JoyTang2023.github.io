## Local Development

No build tools or dependencies are required. To run the site locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JoyTang2023/JoyTang2023.github.io.git
   cd JoyTang2023.github.io
   ```

2. **Open in your browser:**
   ```bash
   open index.html
   ```
   Or simply drag `index.html` into any modern browser.

3. **Make changes** to `index.html` and refresh the browser to preview.

4. **Deploy** by pushing changes to the `main` branch — GitHub Pages will automatically update the live site within a minute or two.
